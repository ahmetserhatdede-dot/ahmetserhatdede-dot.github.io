September 20, 2026 - Java Printing

Class Notes

In Java, System.out.println() prints text and then moves the cursor to a new line. System.out.print() prints text but keeps the cursor on the same line.

Java Example

This program is to demonstrate the difference between System.out.print() and System.out.println(). 

public class Printing
{
    public static void main(String[] args)
    {
        // Prints text and moves to the next line
        System.out.println("Hello world.");
        System.out.println("Another line");

        // Prints both parts on the same line
        System.out.print("Print will add to ");
        System.out.print("the same line!");

        // Prints text and then moves to a new line
        System.out.println(" New line after this!");
    }
}

Sample Output

Hello world.
Another line
Print will add to the same line! New line after this!

What I Learned

I learned the difference between print and println in Java. The challenging part was getting used to which command has which function. I solved this by practicing and getting used to using these similar commands.
